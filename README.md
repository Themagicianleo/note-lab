# Note Lab

A personal, non-commercial web app that listens to your microphone and shows
which musical note is playing, its frequency and how many cents sharp or flat
it is. It is meant for instruments and the human voice, and will include ear
training.

**Privacy:** all audio processing happens on your device. Microphone audio is
never uploaded, stored or sent anywhere.

> Work in progress. This README will grow phase by phase (usage, how detection
> works, measured accuracy, limitations, and how AI help was used).

## Running the tests

Needs [Node.js](https://nodejs.org) 18 or newer. There are no packages to install.

```sh
npm test
```
